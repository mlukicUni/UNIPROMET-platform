# UNIPROMET-platform
WEB platforma UNIPROMET kompanije za razvoj software-a

## Verzija

Trenutna verzija je u `package.json`, istorija izmena u [CHANGELOG.md](CHANGELOG.md).
Svako puštanje na produkcijski server (spajanje `dev` → `main`) je nova verzija sa git tagom `vX.Y.Z`.
Prva zvanična verzija: **1.0.0** (28.10.2026).
